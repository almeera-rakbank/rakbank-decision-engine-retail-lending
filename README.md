# Retail Credit Transformation Programme

## Decision Engine on SAS – Checklist & DBR Tool for Retail Lending

### Overview

This project supports RAKBANK's Retail Credit Transformation Programme by replacing the legacy Dectec credit decisioning platform with a SAS-hosted Decision Engine (DE) and introducing a web-based Checklist & DBR Tool.

The solution covers:

- Personal Loan (PL) applications
- Credit Card (CC) applications
- New-to-Bank (NTB) customers
- Existing-to-Bank (ETB) customers
- Digital channel applications
- Branch and DSA originated applications

### Business Goals

- Increase Straight Through Processing (STP)
- Reduce credit decision turnaround time
- Eliminate manual DBR calculation errors
- Accelerate policy rule deployment
- Improve auditability and decision traceability

### Key Integrations

- SAS Decision Engine
- IBPS Workflow
- AECB Bureau
- Core Banking System
- CAM Report Generation
- Dectec (Parallel Run Phase)

### In Scope

- Eligibility Rules
- DBR Calculation
- Loan Assignment
- Credit Card Limit Assignment
- Decision Outcomes
- Decision Reason Codes
- Audit Trail
- MIS Reporting

### Out of Scope

- Auto Loans
- Mortgages
- SME Lending
- Islamic Products
- Arabic UI
- Collections Workflows
